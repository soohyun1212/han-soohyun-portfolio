# LOBSTER 브랜딩 개선

## 진단

기존 화면은 IA와 프로젝트 설명은 정리되어 있었지만 큰 단색 가재 실루엣이 Hero에만 등장해 사이트 전체로 확장되는 시각 언어가 부족했습니다. 평평한 색면과 프로젝트명만 있는 커버, 직선 위주의 섹션 구분, 반복되는 ‘준비 중’ 표시도 미완성 인상을 만들었습니다.

첨부 레퍼런스에서 외골격의 분절·등딱지의 곡면·좌우 집게 사이의 긴장감을 읽어 그래픽 원칙으로 사용했습니다. 레퍼런스의 신용카드 형태나 인물·브랜드 문구는 가져오지 않았습니다.

## 프로젝트 커버

- MEDI-BRIDGE: 병원 선택에서 진료 이후까지 연결되는 의료 흐름을 아치와 연결점으로 표현.
- aqui: 돌봄과 기록의 연속성을 겹친 고리로 표현.
- 하나투어: 복잡한 갈림길 중 탐색 기준을 드러내는 경로 표현.
- 제주 응급의료: 격자·상태선·측정점으로 판단 정보의 명확성 표현.
- Weverse: 콘텐츠 층과 확대경으로 탐색·발견 표현.
- MOMOA: 일정과 참여·준비의 연결을 체크 모티프로 표현.
- 로켓프레시: 분산된 상품 분류를 정리한 그리드 표현.
- 계원예대: 정보의 면과 층을 펼친 도면으로 표현.

커버는 기존 프로젝트 설명을 바탕으로 만든 편집 그래픽입니다. 실제 앱 화면·사용성 측정 결과·개인 사진을 새로 만들거나 기존 자료인 것처럼 표시하지 않았습니다. 프로젝트 제목·설명·기간·역할·상세 본문 데이터와 IA는 유지했습니다.

그래픽은 재사용할 수 있는 SVG 컴포넌트이며 외부 이미지 생성 서비스에 자료를 전송하지 않았습니다. 프리텐다드 로컬 폰트와 reduced-motion 지원도 유지했습니다.
